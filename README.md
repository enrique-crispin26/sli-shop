### PROYECTOS PERSONALES

**AlisonShop — Asistente comercial automatizado con inteligencia artificial**

*Tecnologías: n8n, JavaScript, Google Sheets, API de WhatsApp Business, OpenAI, Webhooks y JSON.*

* Desarrollé un sistema de automatización de consultas comerciales mediante n8n, integrando WhatsApp Business con Google Sheets y un modelo de inteligencia artificial.
* Implementé lógica en JavaScript para procesar mensajes, buscar productos, verificar precios y disponibilidad, y recomendar alternativas según las necesidades del cliente.
* Configuré webhooks e integraciones API para automatizar la recepción de consultas y el envío de respuestas comerciales.
* Desarrollé scripts para comprobar funcionalidades relacionadas con búsquedas, reservas y prevención de mensajes duplicados.
